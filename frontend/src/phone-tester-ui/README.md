# Phone Tester UI

Standalone mobile Recall UI scaffold.

This app is intended for free exploration outside the guided participant test. It should eventually provide a phone-sized search interface that talks only to the local Recall backend API.

Planned capabilities:

- Search input with text and semantic search options.
- Scrollable result grid with wheel and drag scrolling.
- Item detail/selection events that can be reused by the user-test harness.
